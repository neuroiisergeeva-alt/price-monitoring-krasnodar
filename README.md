# Цены пиломатериалов — Краснодар

Адрес отчета: https://neuroiisergeeva-alt.github.io/price-monitoring-krasnodar/

Отчет собственного склада и конкурентов Лескрафт, Деревообработчик, ДомСтрой, Технодрев. Публикация через GitHub Pages из ветки main и папки / (root). Сохранены группы, исключения, размерные соответствия пользователя, отдельные розница и опт Лескрафта, пересчет в единицу каждой нашей строки и история.

## Включение сайта

Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root). Готовые index.html и assets/ уже публикуются в корне, а исходный шаблон для сборки находится в frontend.html. GitHub Actions собирает сайт и запрашивает повторную публикацию после обновления данных.

## Обновление

Понедельник08:00 МСК (`0 5 * * 1` UTC), а также ручной запуск Actions. GitHub может задержать старт расписания. «Перечитать отчет» в самой таблице загружает опубликованные данные, не запускает сборщик. Настоящее внеплановое чтение запускает владелец через Actions → Run workflow.

Все страницы подключенных каталогов и карточки читаются сервером Actions, браузеру посетителя не требуется доступ к сайтам конкурентов. Неудача сохраняет старую цену и дату и записывается в истории. История сравнивается с предыдущей календарной неделей по Москве. GitHub публичный: таблицу и ее данные может открыть любой человек.

## Файлы поставщиков и ограничения

- Лескрафт: ищется фактически опубликованная ссылка XLSX Краснодар на /prices; дата из ячеек, единицы секции, розница и именно оптовая, без крупного опта. При403, отсутствии ссылки/даты/заголовков сохраняется прежний файл с прежними датами. Изменение структуры строк требует проверки правил, особенно погонажа.
- ДомСтрой: текущая ссылка XLSX Краснодар на /price; читаются все вкладки и реальные вертикальные объединения. Дата публикации неизвестна. Только вкладка «Доска, бруски»: единица штука, А/В принимается какАВ и антисептик допускается по пользовательскому правилу.
- Деревообработчик: текущая ссылка PDF на /documents. Пока PDF совпадает по SHA256 с разобранным источником16.03.2026, повторное чтение подтверждает сохраненные строки безНДС. **Новый изменившийся PDF автоматически не разбирается:** появляется ошибка и уведомление; старые цены/даты остаются до проверки нового файла. Неизвестный сорт не приравнивается кАВ, кроме подтвержденного монтажного бруска.

Неполные размеры/сорта/склейка и неподтвержденные аналоги остаются отдельными ориентирами; не включаются в подтвержденные отклонения. Скандинавский профиль Технодрев20×146 соответствует нашей21×146 по подтверждению13.10.2026, с проверкой сорта, породы и длины.

## Уведомления

При изменениях или сбоях Actions создает/обновляет Issue с датой. Для email уведомлений в GitHub включите Watch → All Activity для этого репозитория и настройте email в своем аккаунте. Список текущих изменений также сохранен в data/changes.md. Уведомления текущего частного отчета ChatGPT работают отдельно; этот репозиторий не меняет доступ к нему.

## Локальная работа

Node22+, Python3.12+, curl. `npm install`; `pip install openpyxl==3.1.5`; `npm run check`; `npm run build`. `npm run refresh` читает источники и сохраняет историю в data/*.json.gz. Секреты ChatGPT/Sites и чужие учетные данные в проект не включаются.


После публикации обновите открытую таблицу сочетанием Ctrl+F5, чтобы браузер загрузил новую версию страницы и стилей.

## Мониторинг Крым

Отдельная таблица: https://neuroiisergeeva-alt.github.io/price-monitoring-krasnodar/crimea/

Наш источник — пиломатериалы-крым.рф, первый конкурент — terem-krym.ru. Данные и история независимы в data/crimea/. Собираются все пять страниц нашего каталога и все страницы подключенных деревянных категорий Терем. Только точные сечения, длины, сорта и профили входят в отклонения; близкие предложения показаны для уточнения. Правила размеров краснодарских конкурентов на Терем не переносятся. Упаковки пересчитываются по фактическому числу досок и полной ширине. Единица берется из каждой нашей строки; сращенные бруски исключены. Если наша подробная таблица не опубликована, источник отмечен для уточнения, цена «от» не выдается за точную цену каждого размера. Первая проверка 13.10.2026 — база истории, а не сравнение с предыдущей неделей.

Сборщик Крым: `python scripts/crawl-crimea.py && node scripts/import-crimea.mjs`. Запускается в общей проверке по понедельникам 08:00 МСК; уведомления Крым формируются отдельно в Issues. GitHub может задержать старт. Кнопка перечитывает уже опубликованные данные.
