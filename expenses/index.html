Сохранение на GitHub

Для просмотра директору достаточно пароля. Чтобы публиковать изменения, подключите свой ключ GitHub.

  1. Откройте создание Fine-grained token в своём GitHub.
  2. Выберите Only select repositories и репозиторий price-monitoring-krasnodar.
  3. В Repository permissions разрешите Contents: Read and write. Выберите срок действия и создайте ключ.
  4. Вставьте ключ в поле ниже.

Ключ используется только для записи в ваш GitHub и хранится в памяти этой вкладки до выхода или перезагрузки. Не отправляйте его директору или в чат.
